Transitioning from standard photorealistic PBR to anime styles is always tricky. If you just plug in basic lighting, your toon characters will look muddy and lose that clean, hand-drawn aesthetic. Cel shading is the backbone of stylized rendering—we take those smooth gradients and snap them into clean, graphic bands of color.

Here is a breakdown of how cel-shading works, how to build it in Unreal Engine, and how to avoid the classic traps that usually pop up when you put it into production.

---

## The Concept: Lighting Vectors vs. Toon Bands

![Cel Shading Vectors and Shadow Threshold](/images/shaderlex/cel_shade_diagram.png)

In realistic shading, light bounces off surfaces smoothly. The math measures the angle between the surface Normal vector (N) and the Light Direction (L), giving us `NdotL`.
- If the surface faces the light, `NdotL = 1` (fully lit).
- If the surface is perpendicular to the light, `NdotL = 0` (the terminator line).
- If the surface faces away, the value is negative (`NdotL < 0`) and represents shadow.

Instead of rendering a smooth gradient from black to white, we intercept this value and snap it into a solid boundary: **Light vs. Shadow**.

---

## Step-by-Step Shader Logic

### Step 1: Measuring the Light Angle
Everything starts with finding out where the light is hitting the mesh:
```hlsl
float NdotL = dot(NormalWS, LightDirWS);
```
The dot product returns a value from `-1.0` to `1.0`. We only care about positive lighting, so we often scale or clamp this value.

### Step 2: Snapping the Shadow Line
Instead of a smooth gradient, we want a hard cutoff. You might think of using a raw comparison like:
```hlsl
float shadow = NdotL > shadowThreshold ? 1.0 : 0.0;
```
But don't do this! A hard threshold creates jagged, pixelated edges (aliasing) that flicker like crazy when the character animates or the camera moves. 

To fix this, we use `smoothstep` to create a tiny, controllable gradient zone that blurs the jagged edges just enough to stabilize them on screen:
```hlsl
float diffuse = smoothstep(0.0, shadowSoftness, NdotL - shadowThreshold);
```

### Step 3: Adding the Silhouette Rim
Anime characters often use a glowing edge (rim light) to separate them from dark backgrounds. We use Fresnel math, which measures how parallel the camera view vector (V) is to the surface normal (N):
```hlsl
float rim = 1.0 - saturate(dot(NormalWS, ViewDirWS));
```
We then mask this rim so it only shows up on the outer edges and multiply it by width and intensity controls:
```hlsl
float rimMask = smoothstep(1.0 - rimWidth, 1.0 - rimWidth + 0.05, rim) * rimIntensity;
```

## HLSL Implementation

Here is a clean custom HLSL block representing a basic toon shading setup:

```hlsl
// Calculate light dot product
float NdotL = dot(NormalWS, LightDirWS);

// Smooth band transition
float diffuse = smoothstep(0.0, shadowSoftness, NdotL - shadowThreshold);

// Calculate camera Fresnel rim
float rim = 1.0 - saturate(dot(NormalWS, ViewDirWS));
float rimMask = smoothstep(1.0 - rimWidth, 1.0 - rimWidth + 0.05, rim) * rimIntensity;

// Blend shadow color and base color
float3 cellColor = lerp(shadowColor, baseColor, diffuse);

// Add glowing outline rim light
float3 finalColor = cellColor + (rimMask * rimColor);
```

## Common Production Traps & Solutions

### 1. The "Dirty Face" Trap
**Why it happens:** When lights rotate or character heads turn, the hard shadow line cuts across the nose, eyes, or mouth in weird, jagged patterns, making the face look deformed or dirty.
**How to fix it:** Senior artists never cel-shade the face using raw geometric normals. Instead, they use a custom face shadow map (look-up texture) or paint custom vertex colors to steer the shadow border smoothly, ignoring the nose protrusion.

### 2. Normal Mapping Interference
**Why it happens:** Putting a detailed normal map on a toon shader creates chaotic, messy dark spots instead of clean toon lines.
**How to fix it:** Use normal maps with low intensity, or blend the normal map out in shadowed areas. You only want normal detail to break the highlight, not the shadow boundary.
