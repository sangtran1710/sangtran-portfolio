If you ask any VFX lead what node they check first when optimizing a game, they'll probably tell you: **Depth Fade**.

Without it, your transparent meshes (smoke, steam, fires, water surfaces) will cut straight through solid geometry (floors, rocks, characters), leaving a harsh, ugly intersection line that looks like a cheap card stuck in the ground. This guide breaks down the math, setup, and performance cost of soft intersections.

---

## The Problem: Hard Clipping

When a translucent particle is placed in the level, it cuts straight through solid 3D geometry. The game engine draws the solid geometry first, then overlays the transparent card.
Where the two surfaces intersect, there is a hard, pixelated edge. This instantly breaks the illusion of volumetrics like smoke or fog, making it look like a cheap flat card stuck into a wall.

To solve this, we want the translucent material to become **completely transparent** right at the intersection line, and fade to full opacity as it moves away from the wall.

---

## How Depth Fade works under the hood

![Scene Depth vs Pixel Depth and Fade Distance Intersection Diagram](/images/shaderlex/depth_fade_diagram.png)

The shader compares two depth values for every pixel rendered on the screen:

1. **Pixel Depth (Object Depth):** The distance from the camera to the translucent particle pixel.
2. **Scene Depth (Background Depth):** The distance from the camera to the solid geometry directly behind that pixel.

By subtracting the Pixel Depth from the Scene Depth, we get the distance between the transparent card and the background geometry:

`Depth Difference = Scene Depth - Pixel Depth`

- If the difference is `0`, the particle is touching the wall (intersection line). We set opacity to `0.0`.
- If the difference is large, the background is far away. We set opacity to `1.0`.
- In between, we interpolate smoothly.

---

## HLSL Code Equivalent

Here is the HLSL code representing the depth fade equation:

```hlsl
// Scene depth soft fade equation
float sceneDepth = ScreenDepthSample(screenUV);
float pixelDepth = input.pixelDepth;
float depthDiff = sceneDepth - pixelDepth;

// Divide by fade distance and clamp between 0 and 1
float fadeAlpha = saturate(depthDiff / fadeDistance);

// Output final opacity
float4 finalColor = float4(baseColor, opacity * fadeAlpha);
```

## Unreal Engine Setup Guide

Unreal Engine has a built-in **Depth Fade** node that does this math automatically:

1. Open your Material.
2. Set the **Blend Mode** in the material details panel to **Translucent**.
3. Create a **Depth Fade** node.
4. Connect the **Fade Distance** input (a scalar value like `100.0` or `200.0` units).
5. Multiply the output of the Depth Fade node with your particle texture's alpha channel.
6. Connect the result to the **Opacity** input.

## Performance & Optimization Tips

While Depth Fade is essential, it comes with a GPU cost:

### 1. Scene Depth Texture Fetch
Translucent materials normally do not write to the depth buffer. However, using Depth Fade forces the GPU to perform a **Texture Lookup** on the Scene Depth buffer for every pixel rendered. If you have thousands of overlapping smoke particles (High Overdraw) all running Depth Fade, you will create a major texture fetch bottleneck.
- **How to optimize:** Only use Depth Fade on large, primary particles (like ground fog or massive cloud explosions) that are guaranteed to clip. Turn it off for tiny sparks, embers, or fast-disappearing debris.

### 2. Mobile Platform Compatibility
On mobile devices (ES3.1 / Metal), depth texture fetches can be slow or unsupported if not configured correctly. Always verify that "Create Mobile Depth Stencil" is enabled in your Unreal Engine project settings.
